# data/

Thư mục này **không được commit** (trừ file README này). Dùng cho:

- `storage/` — file upload (audio, ảnh, bản ghi Speaking, nguồn OCR) do `LocalDiskStorage` quản lý.
- `tmp/` — file tạm khi upload.
- `backups/` — kết quả `pnpm backup` (dump DB + bản sao storage).
- `tests/` — đề thật (CAM/VOL/Pre-IELTS) dạng JSON để import. **Không bao giờ đưa nội dung có bản quyền vào git.**
